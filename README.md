# Offline Skin Cancer Detection

This project is an offline skin lesion classification application. It is designed to run locally, utilizing deep learning models to assist in detecting skin cancer from images.

## Structure
- `data/`: Contains raw, processed, and metadata.
- `models/`: Saved model weights.
- `notebooks/`: Jupyter notebooks for EDA and model experimentation.
- `src/`: Source code for data loading, preprocessing, and training.
- `app/`: Streamlit application code.
- `reports/`: Generated analysis and evaluation reports.
