# Screenshot Portfolio Plan

*To properly document the UI for a portfolio, capture the following screenshots manually. Do NOT fabricate screenshots.*

1. **Login Screen:**
   - Capture the centered login form showing the username/password fields, "Offline Machine Learning Application" subtitle, and the lock icon.

2. **Main Dashboard (Initial State):**
   - Capture the UI immediately after login, showing the clear file uploader, the safety disclaimer, and the sidebar options.

3. **Image Upload:**
   - Capture the UI with an image successfully loaded, showing the original image preview.

4. **Model Output:**
   - Capture the result section showing a prediction (e.g., "Predicted: Non-malignant").
   - Ensure the threshold explanation ("Distance to threshold") is visible.

5. **Probability Visualization:**
   - Capture the interactive progress bar showing the precise percentage and estimated probability.

6. **Image Quality:**
   - Expand the "Image Quality Analysis" section and capture the metrics (Resolution, Brightness, Sharpness) displaying PASS/WARNING statuses.

7. **Grad-CAM:**
   - Toggle the Grad-CAM visualization on and capture the side-by-side comparison of the Original Image and the Grad-CAM Heatmap.

8. **Prediction History:**
   - Navigate to the "Prediction History" sidebar page and capture the interactive dataframe showing logged predictions.

9. **Light Mode:**
   - Ensure at least one comprehensive dashboard screenshot is captured in Streamlit's Light Theme.

10. **Dark Mode:**
   - Ensure at least one comprehensive dashboard screenshot is captured in Streamlit's Dark Theme to demonstrate native theme support.
