# CV / Europass Project Entry

**SKIN VISION — Offline Skin Lesion Analyzer**
- Developed an AI research prototype for binary skin-lesion image classification using a fine-tuned EfficientNet-B0 model and HAM10000-derived data.
- Built a secure offline/local inference application using Streamlit, featuring local authentication, persistent prediction history, and an additional public hosted demonstration.
- Achieved a ROC-AUC of 85.37% on a 1494-image held-out test set through rigorous dataset splitting and transfer learning.
- Implemented Grad-CAM visualization and threshold-distance interpretation to provide explainability for model predictions without making clinical diagnostic claims.
