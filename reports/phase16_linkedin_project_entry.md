# LinkedIn Project Entry

**Project title:** SKIN VISION — Offline Skin Lesion Analyzer

**Description:**
I built an AI research and educational prototype for binary skin-lesion image classification. This project explores how deep learning models evaluate biological image data, focusing on model transparency and explainability rather than clinical diagnosis. Using a fine-tuned EfficientNet-B0 model trained on the HAM10000 dataset, the application provides estimated model probabilities and visualizes which parts of an image influenced the prediction.

**Key Features:**
- Binary classification of Non-malignant vs. Malignant-Suspicious image patterns.
- Fully offline/local inference application with secure local authentication.
- Grad-CAM explainability to visualize model attention.
- Basic image-quality analysis heuristics (resolution, brightness, sharpness).
- Hosted public demonstration for easy access.

**Technologies:** Python, PyTorch, EfficientNet-B0, Streamlit, OpenCV, Grad-CAM.
